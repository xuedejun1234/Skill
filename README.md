# Personal Agent Skills

Reusable skills installed in the user's local Codex skills directory. Each folder contains its own `SKILL.md` and any supporting references or scripts.

| Skill | Purpose |
|---|---|
| `douyin-ide` | Operate and debug Douyin developer tools and mini-game builds. |
| `find-skills` | Discover and install useful agent skills. |
| `mini-game-reverse` | Analyze and reconstruct WeChat/Douyin mini-game projects from packages or caches. |
| `planning-with-files` | Track multi-step work with persistent plan, findings, and progress files. |
| `ponytail` | Prefer minimal, low-complexity coding solutions. |
| `ponytail-audit` | Audit a repository for over-engineering. |
| `ponytail-debt` | Collect and review `ponytail:` deferred-work comments. |
| `ponytail-gain` | Summarize measured simplification impact. |
| `ponytail-help` | Quick reference for Ponytail skills and commands. |
| `ponytail-review` | Review code changes specifically for unnecessary complexity. |
| `reverse-engineer-anything` | Reverse engineer native, managed, web, and packaged artifacts with REA. |
| `taptap-unity-sdk` | Integrate and troubleshoot TapTap Unity login, compliance, purchases, and builds. |

Use a skill explicitly by naming it in the request, for example: `$taptap-unity-sdk`.
